# Raportarea vulnerabilităților

Trimite detaliile prin [formularul de contact](https://www.efacturiplus.ro/app/site/contact), cu subiectul „Securitate”, sau folosește [Private vulnerability reporting](../../security/advisories/new) pe GitHub.
Nu deschide un Issue public și nu testa pe conturi care nu îți aparțin. Nu trimite facturi reale la ANAF în teste.

Versiunile acoperite sunt ultimele versiuni ale modulelor și API-ul `v1`.
